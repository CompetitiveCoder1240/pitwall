# 🏎️ PitWall — F1 2026 Regulations RAG Chatbot

> **PitWall** is an AI-powered technical consultant that lets you query the full FIA 2026 Formula 1 Regulations (all six sections, ~8,000 pages combined) using natural language. Built with a production-grade **Parent-Child RAG pipeline**, **cross-encoder reranking**, and a streaming chat interface.

---

## ✨ Features

- **Parent-Child Chunking** — micro child vectors for precision retrieval, full parent articles sent to the LLM for rich context
- **Two-Stage Retrieval** — ChromaDB vector search → FlashRank cross-encoder reranker
- **Conversational Memory** — history-aware question reformulation for natural multi-turn dialogue
- **Streaming Responses** — token-by-token SSE streaming from FastAPI to Streamlit
- **Anti-Hallucination** — LLM is strictly instructed to cite the regulations or admit ignorance
- **F1 Carbon/Red UI** — dark-themed Streamlit frontend with sidebar, health badge, and suggestion chips

## ⚙️ Setup

### 1. Clone & install

```bash
git clone https://github.com/YOUR_USERNAME/pitwall.git
cd pitwall
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

### 2. Configure environment

```bash
cp .env.example .env
# Edit .env and add your OPENROUTER_API_KEY
```

Get a free key at [openrouter.ai/keys](https://openrouter.ai/keys).

### 3. Add your PDF documents

Place the FIA 2026 F1 Regulation PDFs inside the `data/` folder:

```
data/
├── FIA 2026 F1 Regulations - Section A [...].pdf
├── FIA 2026 F1 Regulations - Section B [...].pdf
└── ...
```

### 4. Run ingestion (once)

```bash
python scripts/ingest.py
```

This reads all PDFs, builds the Parent-Child index, and saves `chroma_parent_child_db/` + `parents.pkl` to the project root. Only needs to be run again if you add or change PDFs.

### 5. Start the backend

```bash
uvicorn backend.api:app --reload
```

The API will be live at `http://localhost:8000`. Check `http://localhost:8000/health`.

### 6. Start the frontend

Open a second terminal:

```bash
streamlit run frontend/app.py
```

Navigate to `http://localhost:8501` in your browser.

## 🔌 API Reference

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET`  | `/health` | Liveness probe — returns `{"status": "ok"}` |
| `POST` | `/chat`   | Streaming chat. Body: `{"session_id": "...", "message": "..."}` |
| `DELETE` | `/session/{session_id}` | Clears in-memory chat history for a session |

The `/chat` endpoint returns a `text/event-stream` of JSON chunks:
```json
data: {"chunk": "token text here"}
data: {"done": true}
```

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Embeddings | `sentence-transformers/all-MiniLM-L6-v2` (local CPU) |
| Vector store | ChromaDB |
| Reranker | FlashRank `ms-marco-TinyBERT-L-2-v2` |
| LLM | `nvidia/nemotron-3-ultra-550b-a55b` via OpenRouter |
| Backend | FastAPI + Uvicorn |
| Frontend | Streamlit |
| Orchestration | LangChain (LCEL) |

- `parents.pkl` and `chroma_parent_child_db/` are gitignored — large binary artifacts regenerated locally
